# Ending conditions and safety
At final chapter, player sees all four philosophies. PATCH always selectable. WALK_AWAY always selectable. REWRITE is selectable if public_trust >= 0 or the player completes a corrective community testimony in the finale. REVEAL is selectable if evidence_count >= 4 or the player completes the final audit in the finale. Never hard-lock to one ending.

| Ending | Choice | Epilogue callback |
|---|---|---|
| PATCH | Install human appeal and audit safeguards | Vượng submits his first honest form |
| REWRITE | Citizen councils ratify rules | Mai's stall displays contradictory prices proudly |
| REVEAL | Publish all reset archives | Lan opens the public memory museum |
| WALK_AWAY | Exit jurisdiction | Cộc stamps a blank departure pass |

Bốp relationship modifies epilogue tone; does not remove endings. Endings are narrative conclusions, not monetization gates.
