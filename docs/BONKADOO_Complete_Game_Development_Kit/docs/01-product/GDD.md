# Game Design Document
## High concept
Tí, a weary Vietnamese office worker, is fired for being too competent but is forbidden from leaving because a fired employee cannot legally receive an exit pass. With Bốp, a sarcastic floating assistant cube, Tí exploits absurd yet internally consistent civic rules and discovers that the municipal AI LOGIC has been overwriting people's records across repeated administrative resets.

## Pillars
1. Every touch creates feedback: object, sound, character or clear clue.
2. Wrong ideas can be useful: discover loopholes, combine tools, persuade NPCs.
3. The world remembers: events alter future dialogue, access and finale tone.
4. Humor is systemic: comedy from player-caused reactions, not walls of jokes.
5. Mystery escalates: file anomalies -> civic rules -> resets -> choice of future.

## Audience and boundaries
Approachable mobile narrative puzzle players; sessions of 3–10 minutes; not precision/reflex gameplay. No graphic violence or jokes attacking protected identities. Humor targets bureaucracy and contradiction. No unwinnable states, random puzzle solutions or required pay-to-progress.

## Input and loop
Observe -> tap/drag/use/combine/talk -> rule evaluation -> immediate feedback -> consequence event -> NPC response -> next scene. Inventory always accessible, context hint optional, settings/pause, save/resume. Touch targets >=44pt equivalent. Offer tap-to-use alternatives to drag. Scene should show interaction within 5 seconds and first payoff within 30 seconds (validation targets).

## Systems
Inventory (stable IDs, acquire/use/combine/consume); world facts and rule predicates; deterministic resolver; consequence event journal; NPC dispositions; Yarn branching adapter; progressive three-tier hint system; checkpoints and replay; four ending outcomes.

## World logic
An official assertion becomes binding when recorded, not when true. Contradictory records cannot be deleted by ordinary staff; only superseded with a higher-authority document. Public signs, stamps, forms, witnesses and queues are manipulable puzzle tools. Every rule requires visible discoverable evidence and a fair solution.

## Chapter arc
1. Last Day at Work — escape office and checkpoint.
2. Invalid Citizen — prove an identity the city refuses to recognize.
3. Bread Revolution — a permit dispute becomes civic unrest.
4. The Misrememberers — recover records of failed resets and Bốp's secret.
5. Who Is Wrong? — confront LOGIC and choose what replaces it.

## Ending contract
PATCH: install oversight and stabilize LOGIC. REWRITE: community rule approval. REVEAL: publish reset archive. WALK_AWAY: leave the jurisdiction. Each must have distinct cinematic/dialogue callback. No ending requires purchases; never hard-lock the player into a single ending.

## Scope control
45 puzzle designs are *content commitments*, not 45 independent code systems. Reuse 8–12 core verbs, shared predicates, NPC behavior archetypes and 2D scene templates. Branch locally, converge at chapter revelations.
